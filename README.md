# ci-cd-labs

Repositorio de laboratorios del módulo de CI/CD.

## Descripción del proyecto

Este repositorio contiene los laboratorios prácticos sobre integración continua y despliegue continuo, utilizando GitHub Actions como plataforma de pipelines.

## Estructura

- `app/` — archivos de la aplicación de ejemplo.
- `.github/workflows/` — definiciones de los pipelines de CI.
